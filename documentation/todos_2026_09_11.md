### usage

when a user has some kind of admin role assigned to one or more of the players and/or has the super admin role assigned 
to their account, then they should be able to be able to select which player admin role the wish to use

for example if a user is a super admin, and also is an admin for aliance 1 & 2 and a power admin for aliance 3, then 
they should be able to select from the following:

* user - act as a normal user with no admin privileges, can modify their own account and players for all aliances they belong to
* player xxx \[aliance 1]: admin - act as an admin for the aliance 1
* player yyy \[aliance 2]: admin - act as an admin for the aliance 2
* player zzz \[aliance 3]: power admin - act as a power admin for the aliance 3
* super admin - act as a super admin for all aliances

the content and functionality of the pages should change based on the selected role.
